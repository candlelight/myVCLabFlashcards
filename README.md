# myVCLabFlashcards

Interactive flashcards for the VC Lab / Venture Institute Cohort VII glossary.

## Use it

Open [VC Lab Flashcards] (https://candlelight.github.io/myVCLabFlashcards) in any browser, or enable GitHub Pages on this repo
(Settings → Pages → Deploy from branch → main → /root) to get a live link.

78 terms across 8 sections, click/tap to flip, arrow keys to navigate,
mark cards "still learning" or "got it" to build a review-only pass.
